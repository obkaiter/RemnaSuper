# Решения миграции TUI

## Терминал

Клиент собирается из C++17 и использует wide-character варианты ncurses,
panel, menu и form. Отдельные PTY принадлежат постоянной оболочке и
внешним заданиям. libvterm обрабатывает управляющие последовательности
и хранит экраны дочерних процессов. В основной терминал попадает только
отрисовка через ncurses, а управляющие строки дочерних программ не уходят
напрямую в SSH-клиент. TERM дочерней программы — `xterm`. Этот профиль
проверяется через PTY. Для обычного списка действий используется собственная
отрисовка через WINDOW, чтобы учитывать ширину Unicode.

Главный цикл опрашивает клавиатуру, PTY и каналы заданий. Скрытый PTY
обрабатывает вывод, поэтому переключение сохраняет cwd, переменные,
процессы и экран. При завершении приложения восстанавливаются настройки
внешнего терминала. После SIGKILL восстановление выполняется через
`stty sane; reset`.

## Действия

Запрос и ответ на вопрос передаются JSON через FD 3. События версии 1
идут через FD 4. Обычный stdout и stderr отделены от событий. Для
внешних терминальных программ действует собственный поток PTY.
Поля обычных действий валидируются до запуска процесса из каталога.
Одноразовые секреты парной диагностики передаются отдельными запросами
по FD и не печатаются в вывод задания. CLI агента и протокол между VPS
сохранены.

Задачи записи TUI используют общую блокировку в `/run/lock`, а затем
штатные блокировки системных модулей. Действия чтения могут выполняться
параллельно. Команда `rs` старой установки и команды из root-оболочки
не участвуют в общей блокировке TUI. Перед отдельными опасными операциями
с конфигурацией выполняется повторное сравнение файла.

## Доставка

Новый установщик загружает исходники из текущего репозитория по HTTPS
и использует пакеты сборки из APT. GitHub Actions также публикует
бинарники как артефакты прогонов. Для загрузки этих артефактов установщиком
понадобится отдельный формат релизов с проверяемой подписью.

Новая сборка устанавливается в закрытую staging-область и проходит
проверку запуска до смены `current`. Замена ссылки запуска атомарна.
`previous` указывает на предшествующую сборку. Установщик TUI не
переписывает исходный каталог Bash-редакции. Блокировка агента и
оставшиеся журналы парной диагностики задерживают обновление и откат.
